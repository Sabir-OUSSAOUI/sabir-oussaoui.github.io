How to install it

Gmail

  1. Click Copy full signature.
  2. Gmail: gear icon, See all settings, General, Signature.
  3. Create new, paste (Ctrl+V) in the box.
  4. Scroll down and click Save Changes.

Outlook (UM6P)

  1. Click Copy full signature.
  2. Outlook web: gear icon, Mail, Compose and reply.
  3. New signature, give it a name, paste.
  4. Choose it as default for new messages, then Save.
